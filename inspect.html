  • Ping đo bằng ICMP tới máy chủ game; máy chủ chặn ICMP thì đo thời gian mở kết nối TCP tới cổng game (10 giây / lần).
  • Ping trên ~150ms hoặc có mất gói → game dễ giật / rớt phòng: thử đổi mạng, tắt tải xuống khác, cắm dây LAN.
  • Flash ăn CPU cao liên tục: đóng bớt tab game, giảm chất lượng hình trong game (chuột phải vào game → Settings / Quality).
  • Game chậm dần sau thời gian dài (RAM tăng mãi): tải lại tab bằng Cmd+R.
