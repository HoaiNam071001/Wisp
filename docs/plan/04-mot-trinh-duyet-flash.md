# 04. 🔄 Một trình duyệt (Electron mới) + engine Flash cho trang cấu hình Flash

Phụ thuộc: 03

**Xong khi:** Bật Flash cho cf4vn.bar bằng icon trên thanh địa chỉ → vào được game như bản 2.3.0; youtube.com mở bình thường, phát được video; người dùng không phải chọn "chế độ" nào.

Đổi 2026-11-15 (người dùng yêu cầu): một chế độ duy nhất với người dùng, Flash là cấu hình theo trang – xem `docs/decisions.md`. Bên dưới vẫn hai engine; trong code / tài liệu gọi là engine **web** / **flash**, không hiện chữ "chế độ" trên UI.

| Engine | Bản | Dùng cho | Ghosthand điều khiển bằng |
|---|---|---|---|
| **web** (mặc định) | Electron ổn định mới nhất lúc làm | Mọi trang | Cổng Wisp (DOM, sự kiện thật) |
| **flash** | Electron 11.5.0 + Pepper Flash 32 (không còn Ruffle – đã bỏ 2026-11-17), tiến trình + cửa sổ riêng | Trang đã cấu hình Flash | Ảnh / chữ (OCR) trong khung game Wisp báo |

Cấu trúc gói sau khi tách:
```
Wisp.app
  Contents/MacOS/Wisp                 ← Electron mới: vỏ app, tab, mọi trang, cổng Ghosthand
  Contents/Resources/game/            ← Electron 11 đi kèm (Electron.app rút gọn) + mã engine Flash
```

Việc:
- 🔄 **Engine Flash** (2026-11-16: spike xong – `flash-engine/main.js` + `protocol.js` (có test), thử bằng `node scripts/flash-engine-try.js [url]`: Electron 11 mở cửa sổ, nhận `open` / `frameRect` / `close` / `quit` qua stdin, báo `ready` / `url` / `title` / `closed` qua stdout. Plugin thật nạp được trong engine (cf4vn.bar: sự kiện `flash` báo `Shockwave Flash 32.0 r0`; thử `WISP_FLASH_PLUGIN=… WISP_FLASH_VERSION=… HOLD_MS=4000 node scripts/flash-engine-try.js https://cf4vn.bar/`) – chưa thử tay vào game. 2026-11-17: vỏ app spawn (`client.js` + `router.js`), thanh công cụ, điều hướng ra ngoài đã xong; Ghosthand: tab có game Flash báo `engine:"flash"`, `frameRect` hỏi engine, lệnh DOM → `flash_page` (`flash/launcher.js` `isFlashTab`, `ghosthand/target.js`) – chưa thử tay, xem checks. Còn: thử tay vào game): mã `flash/` chạy bằng Electron 11 đi kèm, mở cửa sổ Wisp gọn cho trang Flash (cùng giao diện toolbar: URL, tải lại, bảng kiểm tra, icon Flash). Điều hướng ra trang không cấu hình Flash → mở lại ở cửa sổ chính (engine web). Vỏ app mở tiến trình bằng `child_process.spawn` (bỏ `ELECTRON_RUN_AS_NODE` khỏi env), nói chuyện qua stdin / stdout JSON (mở URL, đóng, `frameRect`, trạng thái).
- ✅ **Chọn engine tự động** (2026-11-17: `flash/engine-pick.js` + `flash-engine/router.js` – `tabs.js` `loadInTab` / `will-navigate` đẩy trang Flash thật sang engine; engine tự báo `leave` khi đi ra ngoài domain Flash → mở tab mới ở vỏ app; Ruffle theo từng trang qua IPC `flash:is-ruffle` ở `page-preload.js`; engine có userData riêng `userData/flash-engine` – hai bản Chromium không dùng chung profile, cookie game tách cookie tab web. Engine mở cửa sổ trơn, chưa có thanh công cụ): domain có cấu hình Flash → mở bằng engine flash; còn lại engine web. Logic thuần (`flash/site-config.js` + test): khớp domain gốc / subdomain, mặc định Flash thật, thiếu plugin → Ruffle.
- 🔄 **Icon Flash trên thanh địa chỉ** (2026-11-17: menu chuột phải "Chạy bằng Flash" (mục đánh dấu bật / tắt; nút trên thanh địa chỉ đã bỏ) cho domain đang xem – `flash/site-menu.js`; bỏ danh sách Flash mặc định (cmn.vn, cf4vn.bar) – trang nào cũng phải bật bằng nút. 2026-11-17: chip "Cần Flash – Bật" cạnh ⋮ khi trang có `<embed|object>` .swf mà domain chưa bật (`flash/swf-detect.js` trong preload → IPC `flash:swf` → `flash/swf-hint.js`; bấm = bật Flash cho trang). Đã thử trang local. Còn: thử tay menu): bấm → bảng nhỏ: Flash cho trang này Tắt / Flash thật; đổi → mở lại trang bằng engine đúng. Trang có `<embed|object>` `.swf` mà chưa bật → icon gợi ý (chấm) + một dòng "Trang này cần Flash – Bật".
- ✅ **Cài đặt → Flash** (2026-11-17: `flash/settings-window.js` + `flash-settings.html`; menu hệ thống Flash còn "Cài đặt Flash…", mục ⋮ "Thêm tuỳ chọn Flash…" mở thẳng cửa sổ này; bỏ "Sửa danh sách…" – chưa thử tay, xem checks): danh sách trang đã cấu hình (domain, Flash thật / Ruffle, xoá), cài / thay plugin, mở thư mục plugin / mms.cfg, ghi log allowlist. Thay mục menu Flash cũ (menu hệ thống + ⋮ → "Flash…").
- 🔄 **Chuyển `config.json`** (2026-11-16: đã có `flash/site-config.js` + test – `migrate`, `siteFor`, `engineFor`, `setSite`; `config.flashSites()` suy từ khoá 2.x, `allowDomains()` lấy từ đó. `config.saveFlashSites` ghi `flashSites` + phản chiếu `allowDomains`; "Cho phép Flash trên trang này" / sửa danh sách đã dùng khoá mới. Còn: UI Cài đặt → Flash, icon thanh địa chỉ): `allowDomains` + `DEFAULT_ALLOW` cũ → `flashSites: [{domain, engine:"flash"|"ruffle"}]`; `mode: 'ruffle'` cũ → mọi trang cũ dùng Ruffle. Giữ đọc được `config.json` 2.x, không xoá khoá cũ ngay (bản 2.x quay lại vẫn chạy). `mms.cfg` sinh từ `flashSites`.
- ✅ **Vỏ app lên Electron mới** (2026-11-17: Electron 45.3.3 cho vỏ app; Electron 11.5.0 là gói phụ `electron-flash` (alias npm, x64) – dev lấy qua `require('electron-flash')`, bản đóng gói ở `Resources/game`. `BrowserView`→`WebContentsView`, `new-window`→`setWindowOpenHandler`, `navigationHistory`, sự kiện `console-message` / `did-start-navigation` dạng đối tượng, preload `sandbox:false`. Chuột giả bị bỏ rơi khi cửa sổ ở nền → cờ `disable-backgrounding-occluded-windows`. Đã bỏ cờ `disable-site-isolation-trials` – còn phải thử bấm / gõ vào iframe khác site ở engine web): đổi `package.json`, sửa API đã bỏ: `new-window` → `setWindowOpenHandler`, `BrowserView` → `WebContentsView` (nếu bản mới đã bỏ `BrowserView`), `worldSafeExecuteJavaScript`, `remote`… Bỏ `plugins: true`, `ppapi-flash-*` khỏi tiến trình Web.
- 🔄 **Đóng gói** (2026-11-17: `extraResources` chép `node_modules/electron-flash/dist` → `Resources/game` (mac + win, cả bản personal); thử `npm run dist` mac x64: dmg 208 MB, bản đóng gói mở được cf4vn.bar ở engine Flash. arm64 (2026-11-17): `electron-builder --mac dir --arm64` ra vỏ app arm64 + `Resources/game` x86_64; engine mở cửa sổ / `frameRect` / thoát qua Rosetta. Còn: Windows (cần cài `electron-flash` trên máy Windows hoặc `npm_config_platform=win32`), thử tay bản arm64 trên máy Apple Silicon thật, `updater.js` với zip lớn hơn): electron-builder chép Electron 11 vào `Resources/game` (`extraResources`), mac x64 (engine Flash chạy Rosetta trên Apple Silicon) – thử luôn bản arm64 cho vỏ app; Windows nsis tương tự. `updater.js` vẫn thay cả app (zip lớn hơn), plugin Flash vẫn ở `userData/plugins`.
