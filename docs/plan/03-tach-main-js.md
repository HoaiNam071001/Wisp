# 03. ⬜ Tách main.js theo việc

Phụ thuộc: –

**Xong khi:** Flash + Ruffle, tab, cập nhật, bảng kiểm tra chạy như bản 2.3.0.

- ⬜ `main.js` (1886 dòng) tách theo việc trước khi chuyển: `tabs.js`, `flash/` (`findFlashPlugin`, `writeMmsCfg`, `flash-win.js`, Ruffle, bảng kiểm tra), `menu-app.js`, `updater.js` (đã riêng). Không đổi hành vi, kiểm tra Flash + Ruffle còn chạy.
- ⬜ Mỗi file ≤ ~300 dòng, một file một việc.
